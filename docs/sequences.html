    • sequences

    This api requences will return a list of all the meta-data and sequence information for the corresponding filters. If no filters are added, it will return a list of every sequence available in the database.

    Usage

    python /api/sequences/?[arguments]

    Arguments

    isolate

    (Optional) Isolate ID of the sequence. Example: 11292

    primary_accession

    (Optional) NCBI accession of the sequence. Example: AB009601

    pubmed_id

    (Optional) PubMed id number that is used as a reference for the sequence. Example: 11270607

    exclusion_status

    (Optional) Some sequences are automatically excluded do to various reasons. To exclude these, set the exclusion_status to 0. If you only want excluded sequences, set the exclusion_status to 1. Example: 0, 1

    full_genome

    (Optional) This filter will find all the sequences that have a genome coverage greater than the percentage specified. Example: 90

    EPA_major_clade

    (Optional) This filter will find all the sequences that have the major clade. This can be a singular value or a list Examples: Bats, [Bats, Africa-2]

    (Required) If the EPA_minor_clade filter is included.

    EPA_minor_clade

    (Optional) This filter will find all the sequences that have the minor clade. This can be a singular value or a list. If you are using the EPA_minor_clade, then you must specify the EPA_major_clade filter as well. Example: SEA1a, [SEA1a, SEA2a]

    Example

    This will return are the non-exlucded sequences from the Asian SEA1b clade.

    https://localhost:8000/api/sequences/?EPA_major_clade=Asian&EPA_minor_clade=SEA1b&exclusion_status=0

    Example

    https://localhost:8000/

    sequence

    This will return raw and aligned sequence, and corresponding meta-data for the requested sequence.

    Usage

    api/sequence/<str:seq_id>

    Arguments

    seq_id

    (Required) The NCBI accession of the sequence Example: AB009601

    Example

    https://localhost:8000/api/sequence/AB009601

    sequence reference

    This will return the reference sequence information and a list of all the sequences aligned to the reference sequence.

    Usage

    api/sequence/reference/<str:seq_id>

    Arguments

    seq_id

    (Required) The NCBI accession of the reference sequence. Example: AB041966

    Example

    https://localhost:8000/api/sequence/reference/AB041966

    sequences global

    This will return a list of all the countries and their meta-data and a count of how many sequences are from that country.

    Usage

    api/sequences/global

    Arguments

    None

    Example

    https://localhost:8000/api/sequences/global
